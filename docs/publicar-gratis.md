# Cómo usarla desde el celular en cualquier momento (gratis)

La app es estática: son archivos HTML, CSS y JavaScript sin servidor. Puede alojarse gratis en
GitHub Pages. Esto es lo que hace falta:

- Una cuenta de GitHub (gratuita).
- Un repositorio **público**. GitHub Pages en la cuenta gratuita solo funciona con repositorios públicos.
  El progreso de cada persona no se sube a GitHub: se guarda en su propio celular o computador.
  Lo que sí queda público son las preguntas y el código.

## Pasos

1. Crea un repositorio nuevo, por ejemplo `saber-pro-prep`, en modo **público**.
2. Sube todos los archivos de la carpeta `saber-pro-prep` a la rama `main` (en la página del repositorio, *Add file → Upload files*).
3. Ve a *Settings → Pages*. En *Build and deployment*, elige *Deploy from a branch*, rama `main`, carpeta `/ (root)`.
4. Espera 1 o 2 minutos. La dirección será `https://TU-USUARIO.github.io/saber-pro-prep/`.
5. Ábrela en el celular. Puedes agregarla a la pantalla de inicio: en Chrome de Android, menú → *Instalar aplicación*; en Safari de iPhone, botón de compartir → *Agregar a pantalla de inicio*.

## Sin conexión

Al abrir la app desde esa dirección (https), el navegador guarda los archivos. Después puedes
practicar sin internet. Si cambias la app, abre la página con conexión una vez para que se actualice.

## Otras opciones gratuitas

- Cloudflare Pages o Netlify también ofrecen planes gratuitos para sitios estáticos. Son equivalentes; los pasos cambian.

## Antes de publicar

- Revisa que `docs/plan-pruebas.md` tenga marcadas las pruebas en tu celular.
- Ten presente que las preguntas son originales de práctica, no oficiales.
